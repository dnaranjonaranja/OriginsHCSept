1. Resumen Ejecutivo
Este documento define la arquitectura funcional del MVP de Human Complex. El producto opera bajo el principio de provocación: generar consciencia real a través de preguntas que confrontan al usuario con su comportamiento actual, no con lo que aspira ser.
El modelo integra 4 Pilares y 11 Esferas, con un total de 63 preguntas cerradas que permiten un diagnóstico de aproximadamente 15–20 minutos. La arquitectura está diseñada para entregar valor inmediato al usuario individual mientras genera datos agregados útiles para la organización contratante.
Dos restricciones absolutas rigen todas las decisiones de diseño:
Privacidad por diseño: es técnicamente imposible que la organización acceda a datos individuales del empleado.
Humanismo en cada interacción: no evaluamos, acompañamos. Ninguna pantalla, mensaje o resultado usa lenguaje evaluativo.

2. Modelo Conceptual
2.1 Filosofía del Producto
&quot;No evaluamos, acompañamos. El diagnóstico está diseñado para provocar autoobservación, no para asignar puntajes que el usuario pueda usar como etiquetas.&quot;
El objetivo es que el usuario diga &quot;ya me di cuenta&quot; — no que sepa su puntaje. Las preguntas confrontan la brecha entre lo que el usuario dice valorar y lo que realmente hace.
2.2 Estructura: 4 Pilares × 11 Esferas
El modelo organiza el desarrollo personal en cuatro pilares que representan dimensiones complementarias del funcionamiento humano. Cada pilar contiene esferas que permiten diagnóstico granular.

4. Ciclo de Vida del Diagnóstico
4.1 Temporalidad: Ciclo de 90 Días
Cada campaña de diagnóstico tiene una ventana definida de 90 días desde el momento en que se envía la invitación al usuario. La lógica del ciclo es:
Momento
Evento
Descripción
Día 0
Invitación
El usuario recibe el enlace de acceso. Comienza el ciclo.
Días 1–30
Cuestionario abierto
El usuario puede completar el diagnóstico. Si termina antes del día 30, los recursos se habilitan de inmediato.
Día 31
Cierre del cuestionario
El cuestionario se cierra. Los recursos quedan accesibles hasta el día 90 independientemente de si el usuario completó o no.
Días 31–90
Acceso a recursos
El usuario puede explorar la biblioteca de recursos recomendados según sus resultados.
Día 60
Email 1 — seguimiento
Correo automático. Referencia las áreas de oportunidad del usuario. CTA: &quot;Volver a mis recursos&quot;.
Día 90
Email 2 + cierre
Correo de cierre. El acceso a la plataforma se desactiva para este ciclo. Los datos históricos de nivel se conservan para benchmarks agregados.

Nota: Los datos individuales del usuario (respuestas, resultados, nivel por esfera) se conservan en la base de datos para permitir benchmarks históricos y comparativos en ciclos futuros. La organización nunca accede a datos individuales, solo a promedios agregados.

5. Módulos Funcionales
El MVP se estructura en nueve módulos organizados en tres capas:
Capa de Experiencia Usuario: M1 Onboarding, M2 Diagnóstico, M3 Resultados, M4 Recursos, M5 Acompañamiento
Capa Organizacional: M6 Dashboard B2B, M7 Administración
Capa de Soporte: M8 Autenticación, M9 Notificaciones

5.1 M2: Módulo de Diagnóstico — Detalle
Flujo del módulo de diagnóstico, incluyendo el selector de modalidad:
El usuario completa el onboarding y llega a la pantalla de instrucciones.
La pantalla de instrucciones presenta las reglas de respuesta (últimas 2–4 semanas, sin respuestas correctas, privado).
El usuario accede al selector de modalidad: &quot;Diagnóstico completo&quot; o &quot;Por esfera&quot;. El botón Comenzar permanece inactivo hasta elegir.
Si elige &quot;Por esfera&quot;, debe además seleccionar la esfera específica de las 11 disponibles.
El cuestionario se presenta con barra de progreso, badge de pilar/esfera activo y guardado automático por respuesta.
Al finalizar cada bloque de esfera (en modalidad por esfera), el sistema presenta el resultado parcial y la opción de continuar con otra esfera o cerrar sesión.
Al completar el diagnóstico completo, el sistema procesa y redirige a la pantalla de resultados.
5.2 M9: Módulo de Notificaciones — Reglas de Comunicación
Los dos emails automáticos del ciclo siguen estas reglas:
Email del día 60: referencia el nombre de las esferas más bajas del usuario (no el número). CTA directo a la biblioteca de recursos. Tono de acompañamiento, no de urgencia.
Email del día 90: cierre del ciclo. Mensaje de despedida. Recuerda que el acceso se desactiva ese día. No incluye score numérico.
Máximo 2 emails automáticos por ciclo. Sin notificaciones push en MVP.
Todos los emails incluyen enlace de desuscripción en un clic.
